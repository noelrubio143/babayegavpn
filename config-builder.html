Gumawa ng server config

Parehong fields ng Custom Config screen mo. Pag ni-save, direktang na-a-update ang config.html mo sa GitHub — kukunin ng app ito sa susunod na Fetch.

1. GitHub repo

Hindi na-save/na-transmit ang token mo kahit saan liban sa GitHub API — nasa memory lang ito habang bukas ang tab na ito. Isara ang tab pagkatapos gamitin kung shared/public computer. Gumamit ng fine-grained token na naka-scope lang sa isang repo. Hindi ito i-se-save sa file na ito — ikaw mismo maglalagay tuwing gagamitin.

2. Kasalukuyang mga config

Mag-connect muna sa itaas para makita ang listahan.
